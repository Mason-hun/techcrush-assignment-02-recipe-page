A responsive recipe page built with **HTML5 and CSS3** as part of my TechCrush Frontend Development Bootcamp.

The project recreates a provided recipe-page design while focusing on semantic HTML, responsive layouts, typography, spacing, and accessibility.

## 🧠 Key Learnings

This assignment helped me understand that good frontend development is not only about making a page look similar to a design.

I practiced thinking about:

* **Semantic structure** — using elements such as `<main>`, `<article>`, and `<section>` to give the content meaningful structure.
* **Responsive design** — designing layouts that adapt to different screen sizes rather than relying on fixed dimensions.
* **The Box Model** — understanding how margin, padding, borders, and content dimensions affect layout.
* **Accessibility** — providing meaningful alternative text for images and maintaining a logical heading structure.
* **Visual accuracy** — comparing my implementation against the provided design and refining spacing, typography, colors, and layout.
